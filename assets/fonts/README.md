# Bundled UI font

`AdwaitaSans-Regular.ttf` is bundled so the metadata overlay remains readable
and self-contained without depending on a host font installation or GUI
toolkit. It is an unmodified copy from the Adwaita Sans 49.0 distribution.

Adwaita Sans is licensed under the SIL Open Font License 1.1. The full license
and copyright notices are retained in `AdwaitaSans-LICENSE.txt`.
